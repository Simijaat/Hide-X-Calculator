# PR1 - Foundation + Private Calculator/Vault

## What was implemented
- Refactored `VaultSecurityManager.kt` to use PBKDF2 with HMAC-SHA256 for secure PIN hashing. Random salts are generated via `SecureRandom` and stored alongside hashes using Base64 encoding in `EncryptedSharedPreferences`.
- Added an inactivity timer and auto-lock logic to `VaultSecurityManager.kt`, monitored via a `lifecycleScope` coroutine in `MainActivity.kt`.
- Applied `FLAG_SECURE` to the `MainActivity` window to block screenshots and recent-task previews, adhering to Android security best practices.
- Enhanced the `CalculatorViewModel.kt` parser logic to natively handle division by zero (catching `Infinity` and `NaN`), added state management to distinguish between new calculations and active input (`isResult`), and introduced a functional `DEL` action.
- Built out a discrete, two-step PIN setup flow in `CalculatorViewModel.kt` triggered entirely within the calculator context (enter PIN -> `=` -> verify PIN -> `=`).
- Added the `DEL` button to the `CalculatorScreen.kt` UI layout.
- The `VaultScreen.kt` remains a scaffolded dummy screen ready to house feature tools.

## Important architectural decisions
- **Jetpack Compose**: Selected for a modern, scalable UI toolkit.
- **Hilt (Dagger)**: Essential for maintainable dependency injection, especially as the app grows with VPN, ad-blocking, etc.
- **EncryptedSharedPreferences**: Used for storing the vault PIN hash and salt. It leverages Android KeyStore for secure, encrypted local storage.
- **Security Logic**: Hardened by shifting from plaintext PIN storage to a PBKDF2 approach (100,000 iterations, 256-bit key).
- **MVVM Architecture**: ViewModels manage state, decoupling UI from business logic. StateFlows provide reactive security state to the Navigation graph to force lock-outs.

## Known Issues / Limitations
- Calculator logic uses a simple recursive descent parser which relies on Doubles and may encounter floating point inaccuracies for some advanced calculations.
- While `FLAG_SECURE` prevents screenshots, advanced rooting could still potentially inspect memory.
